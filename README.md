# Event Ticket Booking System – Java Day 62

## Description
A Java application for managing event ticket bookings, tracking seat availability and calculating ticket revenue.

## Features
- Book event tickets
- Check available seats
- View all bookings
- Search bookings by ID
- Cancel existing bookings
- Calculate total revenue
- Save booking records permanently

## Technologies
- Java
- ArrayList
- Object-Oriented Programming
- File Handling

## Files
- `Main.java`
- `bookings.txt`

## How to Run
```bash
javac Main.java
java Main
```

## Concepts Used
Classes, Objects, Constructors, ArrayList, Searching, Removing Objects, File Handling and Calculations.
